## Customization Guide

### Updating Your Information

1. **Contact Information** (index.html, line ~280)
   ```html
   <p><i class="fas fa-envelope"></i> Email: contact@kmmediaventures.com</p>
   <p><i class="fas fa-phone"></i> Phone: (Your Phone Number)</p>
   ```

2. **Social Media Links** (index.html, lines ~265-275)
   - Update Facebook link: Replace `https://www.facebook.com/kmmediaventures`
   - Update Instagram link: Replace `https://www.instagram.com/kmmediaventures`
   - Update YouTube link: Replace `https://www.youtube.com/@kmmediaventures`

3. **Gallery Images**
   - Replace placeholder images with your own photography
   - Update image alt text for better SEO

4. **Video Embeds**
   - Replace YouTube video IDs in iframe sources
   - Format: `https://www.youtube.com/embed/VIDEO_ID`

### Color Scheme

The dark theme colors are defined in `styles.css` (lines 1-7):

```css
:root {
    --primary-color: #1a1a1a;      /* Dark background */
    --secondary-color: #2d2d2d;    /* Slightly lighter background */
    --accent-color: #ff6b6b;       /* Red/coral accent */
    --accent-color-2: #4ecdc4;     /* Teal accent */
    --text-color: #e0e0e0;         /* Light text */
    --text-light: #b0b0b0;         /* Lighter text */
    --border-color: #404040;       /* Border/divider color */
}
```

Modify these values to match your brand colors.

## Getting Started

1. Clone this repository
2. Open `index.html` in your web browser
3. Customize the content with your information
4. Deploy to GitHub Pages or your hosting service

## Deployment on GitHub Pages

1. Go to your repository settings
2. Navigate to GitHub Pages section
3. Select `main` branch as source
4. Your site will be available at `https://kmmediaventures.github.io/`
